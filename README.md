# Pizza Calculator 🍕

## 📖 Introduction

This project is a beginner Python exercise from Section 3 of *Teach Your Kids to Code*. It introduces mathematical operations and user input through a simple pizza cost calculator.

The program asks the user how many pizzas they want and the price of each pizza. It then calculates the subtotal, adds an 8% sales tax, and displays the final amount.

## 🖥️ Program Overview

### Pizza.py

**What it does:**
1. Asks the user how many pizzas they want.
2. Requests the cost of each pizza.
3. Calculates the subtotal by multiplying the quantity by the price.
4. Calculates the sales tax at 8%.
5. Adds the sales tax to the subtotal.
6. Displays the complete cost breakdown.

**Expected output:**

```text
How many pizzas do you want? 3
How much does each pizza cost? 12

The total cost is $ 38.88
This includes $ 36 for the pizza and
$ 2.88 in sales tax.
```

*Example calculation:*

- Number of pizzas: 3
- Cost per pizza: $12
- Subtotal: $36
- Sales tax (8%): $2.88
- Final total: $38.88

## 🛠️ What I Learned

- **Variables:** Storing quantities, prices, and calculated values.
- **User input:** Collecting information using `input()`.
- **Numerical operations:** Using multiplication and addition to calculate costs.
- **Percentages:** Converting 8% into its decimal representation, `0.08`.
- **Calculations:** Separating a problem into smaller mathematical steps.
- **Output:** Presenting calculated information using `print()`.

## 🚀 How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in your Python IDE.
4. Run the program:

```bash
python Pizza.py
```

Enter the number of pizzas and the price per pizza when prompted.
